# Demo fast path

After a finalized deployment with verified source parity: landing → connect or silently restore an authorized injected wallet → `/start` → create profile → issue a challenge → publish it on a genuine public surface → register its HTTPS URL → `/p/[id]/verify` → inspect the contract result and derived tier → issue proof → `/proof/[id]` → compatible `/g/[id]` → join on-chain → `/g/[id]/room` only after a fresh `is_member=true` read. GitHub registration uses `https://github.com/<username>`; the contract derives the canonical API URL.

Landing examples are illustrative, not live proof. No complete lifecycle has been verified against the current deployment.
